# Kali Dinali — App Downloads

Official APK downloads for the **Kali Dinali** shop management app.

## Latest release

See the [Releases](../../releases) tab on the right and download `app-release.apk` from the latest release.

## Install

1. Download the APK to your Android phone.
2. Open it (you may need to allow "Install unknown apps" for your browser/file manager once).
3. Install and open Kali Dinali.

This repository contains release builds only — no source code is published here.
